# Contributing

Thank you for helping improve MageBooster modules.

- Bug reports and suggestions are welcome as GitHub issues.
- Pull requests: keep them small and focused, follow the Magento 2 coding standard (`phpcs --standard=Magento2`) and keep PHP 8.0 compatibility.
- By submitting a pull request you agree that WebWorks 101 OÜ may use, modify and distribute your contribution under the module's licence.

The source code is published for transparency. Using it in a store requires a licence; see `LICENSE.txt` in each repository.
